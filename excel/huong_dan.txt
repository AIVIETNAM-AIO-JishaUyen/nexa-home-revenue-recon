NEXA HOME - ĐỐI SOÁT DOANH THU 2025: FILE POWER QUERY
File này nạp 4 file dữ liệu và 4 bảng danh mục bằng Power Query, rồi so Flash (báo cáo nhanh của phòng Kinh doanh) với sổ cái (sổ kế toán của phòng Tài chính).

CÁCH DÙNG
1. Mở sheet Cai_dat, sửa ô B2 thành đường dẫn thư mục chứa dữ liệu (thư mục data của dự án), ví dụ D:\Nexa\data
2. Chọn Data > Refresh All (Dữ liệu > Làm mới tất cả). Không cần sửa truy vấn nào.
3. Xem sheet Kiem_tra: cột Đạt phải là TRUE ở mọi dòng.
Nếu Excel hỏi về mức riêng tư (privacy level) của nguồn dữ liệu: chọn Organizational cho cả thư mục dữ liệu và file này, hoặc vào Data > Get Data > Query Options > Privacy và chọn Ignore the Privacy Levels.

CÁC SHEET
Huong_dan: trang này.
Cai_dat: ô đường dẫn thư mục dữ liệu (tên FolderPath).
Kiem_tra: so 13 chỉ tiêu với bảng tổng kiểm soát QC_Summary của đề. Nhãn nguồn [QC].
Bay_du_lieu: 5 bẫy khi nạp dữ liệu, mỗi bẫy có số trước và sau khi xử lý, chỉ rõ truy vấn và bước xử lý.
Chenh_lech_thang: Flash, sổ cái, chênh lệch theo từng tháng và cả năm.
Chenh_lech_kenh: Flash, sổ cái, chênh lệch theo kênh bán (cửa hàng, online, chưa gắn kênh).
Flash: bảng Flash sau khi xử lý.
Cua_hang: danh mục cửa hàng.

QUY ƯỚC
Chênh lệch = Sổ cái - Flash. Số âm nghĩa là sổ cái thấp hơn Flash.
% chênh lệch trên bảng tháng chia cho Flash.
Tiền: USD (đô la Mỹ). Tổng cột line_amount, net_amount ở sheet Kiem_tra cộng thẳng nhiều loại tiền, chỉ để kiểm tra đã nạp đủ, không phải doanh thu.

CODE CÁC TRUY VẤN
Mỗi truy vấn có file .m tương ứng trong thư mục excel/queries của dự án. File này được dựng lại từ các file .m bằng script excel/build_workbook.ps1.
